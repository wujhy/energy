1. Java 源文件按 UTF-8 无 BOM + LF 写入，避免 PowerShell 默认编码。
2. 不修改或提交 `03code/energy/sql/rysqlite3.db`、`LoginInterceptor.java`、`.codegraph/`。
3. 代码任务先用 `.codegraph` 看调用面，再小步修改。
4. 功能优先，测试只覆盖核心共享逻辑和高风险回归。
5. 提交前必须执行 `git diff --check`，审查 staged diff 后再 `git commit`。
