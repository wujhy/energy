## 已归档计划

## 维护规则

1. 新任务优先写入 `当前计划任务.md`，长期背景再同步到 `蓄电池采集整合计划.md` 或 `energy_refactor_current_plan_20260622.md`。
2. 完成的任务从当前任务列表移到“近期已完成”，必要时只保留提交号和一句结果。
3. 不再新增零散计划文档；确需新增时先判断能否并入当前主文档或辅助参考。
4. 协议原件、图片、Word 方案和运行态数据库不参与计划归档。
