# 实时模型字段矩阵

更新时间：2026-08-04

本文承接 `TASK-REALTIME-FIELD-AUDIT-001`，用于约束标准实时模型、兼容投影和当前态消费边界。当前结论只覆盖代码中已经落地的字段；现场协议、单位或算法未确认的字段保持空值或兼容投影，不允许在内部计算链路写假默认值。

## 总体规则

1. 当前态业务优先读取 `BatteryModuleRealtimeSnapshotService.getCachedSnapshot(packNum)`，只使用 `BatteryModuleRealtimeSnapshot`、`BatteryModuleGroupRealtime`、`BatteryModuleCellRealtime`。
2. `getCachedSnapshot(...)` 只读 Ehcache `battery-realtime-snapshot`，不回源实时表；缓存由采集完成后的 `refreshAfterPoll(...)` 写入。
3. 快照新鲜度由 `battery-realtime-snapshot` TTL 和 `BatteryModuleRealtimeSnapshot.refreshedAt` 共同约束，消费者不得改用历史表时间或旧 Redis 缓存时间判断当前态有效性。
4. `BatteryReportLog`、`BatteryMonitor`、`packParam`、`monitorData` 只保留给历史查询、历史导出、旧兼容入口和明确的兼容同步处理。
5. `project.iot` / `iot.battery` 下旧入口不作为新实时链路消费方，后续只做删除或编译兜底。

## 当前态消费者边界

| 消费方 | 当前状态 | 后续边界 |
|---|---|---|
| 控制前置判断 `ControlBattery` / `ControlBatterySet` | 已直接读取实时快照 | 缺快照时早返回，不回源历史日志 |
| 容量预测 `CapacityPredictionProcessor` / `BatteryPredictorServiceImpl` | 已使用组/单体实时实体 | 算法字段缺失保持 null，不在控制 adapter 内计算结果 |
| 内阻基准与统计 `ConfigurationBatteryServiceImpl`、`StatBattery*` | 已有实时实体入口，仍保留历史/兼容接口 | 继续减少 `BatteryMonitor` 适配，只保留历史导出 |
| 页面/大屏 `ScreenServiceImpl` | 已读取实时快照，DTO 保留 `BatteryReportLogIndex.packParam` 兼容输出 | 大屏相关已完成且基本稳定，后续不再默认扩展；对外结构继续兼容，内部不得再查历史当前态 |
| JSON/TCP 上报 `DataReportJob` | 已读取实时快照 | 继续保留协议 DTO，不恢复 `jsonTcpRealtimeSourceEnabled` 切源判断 |
| 告警 `AlarmContextProcessor` / `BatteryAlarmEvaluationService` | 已基于标准实时模型和状态/阈值来源上下文 | 陈旧快照只提交状态告警；旧位图专属告警保持 unsupported，等待现场来源确认 |
| 历史查询 `BatteryReportLogController` / `BatteryReportLogServiceImpl` | 继续查 `dev_battery_report_log` | 不迁移到实时表 |
| 旧入口 `project.iot` / `iot.battery` | 旧兼容路径 | 不接新实时链路 |

## 未确认项

1. 内阻、连接条电阻、容量、SOC/SOH、放电时长等字段单位和算法口径仍需现场确认；其中 `disChargeDuration`、`residualDischargeDuration`、`backupDuration` 当前按分钟记录待确认。
2. `batteryPackStatus` 当前可作为对外兼容投影和 `_5` 门控，但不代表内部运行态唯一来源。
3. `resistanceTestStatus` 已结合 `_1/_6` 运行态和 `BatteryModeStatusService` 做对外投影；内部运行/结束判断仍以生命周期、running optLog 和模式状态为准。
4. `deviceWorkStatus` / `deviceWorkIOStatus` 标准 600 链路暂无生产方，当前仅按 null-safe 对外透传；未确认来源前不参与内部运行态判断。
5. 告警新链路已不依赖旧状态查询补上下文；未确认来源的旧位图告警继续保持 unsupported。
